Common HTML Entities:

  • &amp; = & (ampersand)
  • &lt; = < (less than)
  • &gt; = > (greater than)
  • &quot; = " (double quote)
  • &apos; = ' (apostrophe)
  • &nbsp; = non-breaking space
  • &copy; = © (copyright)
  • &reg; = ® (registered)
  • &trade; = ™ (trademark)
