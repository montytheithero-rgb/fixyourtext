Filter Lines by Keyword

Filter your list to show or hide lines matching a specific keyword. Choose case sensitive matching and see how many lines match.

0 characters

Filter Options:

How to Use:

  1. Paste or type your list in the input area (one item per line)
  2. Enter the keyword you want to search for
  3. Choose to show matching lines only or hide matching lines
  4. Select case sensitive if you want exact case matching
  5. Click "Filter Lines" to process your list
  6. See the filtered result and count of matching lines
  7. Click "Copy" to copy to clipboard or "Download" to save as a file

Options Explained:

  • Show matching lines only: Displays only lines that contain the keyword
  • Hide matching lines: Displays all lines except those containing the keyword
  • Case sensitive: When enabled, "Apple" and "apple" are treated as different. When disabled, case is ignored.

Keyboard Shortcuts:

  • Ctrl + Enter (or Cmd + Enter): Filter lines
  • Ctrl + C: Copy when output is focused
