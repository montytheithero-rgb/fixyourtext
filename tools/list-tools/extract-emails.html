Extract Email Addresses from Text

Scan your text and extract all email addresses. Optionally remove duplicates, and see how many email addresses were found.

How to Use:

  1. Paste or type your text in the input area
  2. Optionally check "Remove duplicate emails" to eliminate duplicates
  3. Click "Extract Emails" to scan and extract all email addresses
  4. See the extracted emails in the output area (one email per line)
  5. See the count of emails found in the status message
  6. Click "Copy" to copy to clipboard or "Download" to save as a file

What This Tool Does:

  • Scans your text for email addresses using a regex pattern
  • Extracts all valid email addresses found in the text
  • Displays each email on a separate line
  • Optionally removes duplicate email addresses
  • Shows the total count of emails found

Email Pattern:

  • Matches standard email format: username@domain.com
  • Supports letters, numbers, dots, underscores, plus signs, and hyphens
  • Validates domain structure with top-level domain

Keyboard Shortcuts:

  • Ctrl + Enter (or Cmd + Enter): Extract emails
  • Ctrl + C: Copy when output is focused
