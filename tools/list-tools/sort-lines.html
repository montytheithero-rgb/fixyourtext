How to Use:

  1. Paste or type your list in the input area (one item per line)
  2. Choose a sort type: A→Z, Z→A, by length (shortest first), or by length (longest first)
  3. Click "Sort Lines" to process your list
  4. See the sorted result in the output area
  5. Click "Copy" to copy to clipboard or "Download" to save as a file

Sort Types Explained:

  • A → Z: Sort lines alphabetically in ascending order
  • Z → A: Sort lines alphabetically in descending order
  • By Length (Shortest first): Sort lines by character count, shortest lines first
  • By Length (Longest first): Sort lines by character count, longest lines first

Keyboard Shortcuts:

  • Ctrl + Enter (or Cmd + Enter): Sort lines
  • Ctrl + C: Copy when output is focused
